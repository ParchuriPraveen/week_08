1. JavaScript Variables

Variables are used to store data.

var

Re-declaration and re-assignment possible.

let

Re-assignment possible, same-scope re-declaration not allowed.

const

Re-assignment and re-declaration not allowed.

2. JavaScript Data Types

Data types define the type of value stored in a variable.

Primitive Data Types

Number, String, Boolean, Undefined, Null, BigInt, Symbol.

Non-Primitive Data Types

Objects, Arrays and Functions.

3. JavaScript Operators

Operators perform operations on values and variables.

Operator Meaning

-Subtraction
*Multiplication
/Division
%Modulus
**Exponentiation
++Increment
--Decrement
